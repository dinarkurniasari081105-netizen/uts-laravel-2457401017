## 🛠️ Langkah-Langkah Instalasi
1. Clone repository dan instal dependensi (`composer install`, `cp .env.example .env`, `php artisan key:generate`).
2. Atur konfigurasi database dan lakukan migrasi: `php artisan migrate:fresh --seed`.
3. Jalankan server lokal: `php artisan serve`.
